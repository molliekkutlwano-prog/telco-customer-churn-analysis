# 📊 Telco Customer Churn & Revenue Protection Analysis

## 📌 Project Overview
An end-to-end data analytics project evaluating **7,043 subscriber records** to identify core churn drivers, reduce attrition, and safeguard Monthly Recurring Revenue (MRR).

## 🛠️ Tools & Technologies Used
* **Microsoft Excel / Power Query:** Data hygiene, null value resolution, zero-tenure standardization, and feature engineering.
* **Microsoft Power BI:** DAX measures, dynamic canvas layout, churn heatmaps, and price vulnerability visualizers.
* **Microsoft PowerPoint:** Executive deck presentation.

## 💡 Key Business Findings
* **Contract Risk:** Month-to-month contracts experience a **42.71% churn rate** vs. **2.83%** for 2-year contracts.
* **Price Floor Friction:** Customer defection spikes heavily above the **$70/month** billing threshold.
* **Payment Method Attrition:** Manual **Electronic Check** users show over **45% churn**.
* **Demographic Neutrality:** Gender variance across churn is negligible (**0.76%**).

## 🎯 Executive Recommendations
1. **Contract Upgrades:** Offer a 5% monthly discount to migrate month-to-month users to 12- or 24-month terms.
2. **Bundle Premium Tiers:** Include free Tech Support or Online Security on $70+ Fiber plans.
3. **90-Day Early Care:** Automated onboarding workflows to reduce early tenure drop-offs.
4. **Auto-Pay Incentive:** $10 bill credit for switching to automated direct debit.
